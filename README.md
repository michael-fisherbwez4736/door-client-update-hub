## Common Issues

- When the launcher fails to start, confirm that all extracted files remain in one folder.

- When performance choices have no visible effect, restart the launcher and inspect the active profile.
- If the download cannot be reached, retry with a reliable network connection or use the direct build link.
- Replace the current files with the latest build if the installation appears to be outdated.
- If local data cannot be saved, verify that your account has write permission for the launcher directory.
